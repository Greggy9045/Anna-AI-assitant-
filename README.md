🌸 About Anna

Anna is an experimental AI companion built around one simple idea: AI should feel less like a tool and more like someone you can talk to.

Rather than focusing solely on commands and productivity, Anna aims to create a more natural, personal, and welcoming experience through an interactive desktop interface and multiple sources of contextual information.

The goal is to build an AI that doesn't just respond to requests, but gradually becomes a more personal part of your everyday digital life.

✨ Features
🖥️ Custom Desktop Interface — A modern graphical interface built with Python and CustomTkinter.
💬 Interactive Conversations — A simple chat-style input system for communicating with Anna.
🌈 Animated Visuals — Custom animated glowing elements that give Anna a little personality.
🎨 Custom Themes — Multiple visual themes and color schemes.
🧠 Message Processing — A dedicated message-processing module for interpreting user input.
📍 Contextual Information — Functions designed to retrieve useful information about the user's environment.
🔔 Desktop Notifications — Native Windows notifications for reminders and other events.
⚙️ System Integration — Access to selected system information and controls.

🚀 Getting Started
1. Clone the repository
bash
git clone https://github.com/Greggy9045/Anna-AI-assitant-.git

2. Navigate to the project directory
bash
cd Anna-AI-assitant-

3. Install dependencies

Make sure you have Python 3.10 or newer installed.

Install the required packages:

bash
pip install customtkinter pillow psutil pyautogui geocoder python-weather pycaw winotify comtypes

4. Launch Anna
bash
python window.py


Note: Anna currently uses several Windows-specific libraries and system integrations. A Windows environment is recommended.

🧠 The Vision

Anna is an ongoing experiment in creating a more personal kind of artificial intelligence.

The long-term vision is to develop an assistant that can:

Understand context instead of simply processing isolated commands.
Remember relevant information and interactions.
Adapt to the user's habits and preferences.
Interact with the computer and its environment.
Provide a more natural conversational experience.
Bring together multiple information sources to create a richer understanding of the world.

The idea is simple:

Why should an AI only be something you use, when it could become something you genuinely enjoy interacting with?

⚠️ Current Development Status

Anna is an experimental project under active development.

The current repository contains the desktop interface, animated elements, message-processing logic, and several system utility functions.

Important: A fully connected conversational AI backend is not yet implemented in the current version. The project is a work in progress, and some features may be incomplete or subject to change.

🔒 Privacy

Anna is intended to become a personal desktop companion.

Some existing functionality accesses system information, location-related data, and desktop controls. Be aware of what permissions and integrations are enabled when running the application.

Always review the source code before running software that interacts with your system.
